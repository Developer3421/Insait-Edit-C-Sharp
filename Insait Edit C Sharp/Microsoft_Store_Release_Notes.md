# What's New in This Version

**Kilo Code** continues to evolve with powerful new features and improvements! Here's what's new:

### ✨ Added
- **Kilo CLI Support**: Introducing native support for Kilo CLI functionality, enabling more efficient code referencing and navigation throughout your projects.

### 🔧 Fixed
- **Roslyn Tooltip Issues**: Resolved problems with Roslyn tooltips not appearing correctly. Tooltips now display reliably across the interface.
- **Kilo CLI Tooltip Issues**: Fixed Kilo CLI tooltip problems for improved user experience.
- **Angle Bracket Tooltips in AHAML Files**: Fixed tooltip rendering for content starting with the `<` symbol in AHAML files, ensuring proper display of HTML/XML-like syntax hints.

### 🔄 Changed
- **Application Structure Updated**: The application architecture has been refactored and modernized.
  - **Important for Custom Translations**: Due to structural changes, custom interface translations need to be recreated according to the new English baseline standard. Please refer to the documentation for guidance on updating your custom translation files to match the new interface structure.

### 💡 Note for Users
If you've created custom interface translations, we recommend reviewing and updating them to align with the new application structure. The updated English baseline provides improved consistency and accuracy across all interface elements.
