## English

**Insait Edit** is a modern Windows desktop IDE built for C# and .NET developers. Everything you need to go from idea to finished, packaged application is right here — no switching between tools, no configuration headaches.

---

### Write better code, faster

Insait Edit comes with a hand-crafted editor that understands your code. As you type, the IDE offers smart completions, explains what each method does, catches errors before you even run the project, and suggests one-click fixes. Whether you are writing C#, F#, or Avalonia XAML, the editor keeps up with you every step of the way.

---

### Everything in one window

Open a project, browse files, search across the entire codebase, manage NuGet packages, check your Git history, run the app, and read the output — all without leaving the IDE. A built-in terminal is always a keyboard shortcut away when you need it.

---

### From code to packaged app in minutes

Insait Edit handles the full lifecycle of a desktop application. Create a new project, build and run it during development, publish a release build, and wrap it in a signed MSIX installer — all from the same interface. No manual command lines required.

---

### GitHub, right inside the IDE

Commit, push, pull, browse branches and history — the Git panel has everything you need for day-to-day source control. GitHub Copilot CLI is also integrated, so you can get AI assistance without ever opening a browser tab.

---

### Speak your language

Insait Edit ships with a built-in UI in **English, Ukrainian, German, Russian, and Turkish**. Need another language? You can import a custom translation in seconds.

---

### Built for Avalonia, WPF, WinForms, and more

Start a new Avalonia, Windows Forms, WPF, console, or class library project from a clean template and hit the ground running. The IDE understands the differences between project types and adapts the build and run experience accordingly.
