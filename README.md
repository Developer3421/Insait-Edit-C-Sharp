## English

**Insait Edit** is a modern Windows desktop IDE built for C# and .NET developers. Everything you need to go from idea to finished, packaged application is right here — no switching between tools, no configuration headaches.

---

### Write better code, faster

Insait Edit comes with a hand-crafted editor that understands your code. As you type, the IDE offers smart completions, explains what each method does, catches errors before you even run the project, and suggests one-click fixes. Whether you are writing C#, F#, or Avalonia XAML, the editor keeps up with you every step of the way.

---

### Everything in one window

Open a project, browse files, search across the entire codebase, manage NuGet packages, check your Git history, run the app, and read the output — all without leaving the IDE. A built-in terminal is always a keyboard shortcut away when you need it.

---

### From code to packaged app in minutes

Insait Edit handles the full lifecycle of a desktop application. Create a new project, build and run it during development, publish a release build, and wrap it in a signed MSIX installer — all from the same interface. No manual command lines required.

---

### GitHub, right inside the IDE

Commit, push, pull, browse branches and history — the Git panel has everything you need for day-to-day source control. GitHub Copilot CLI is also integrated, so you can get AI assistance without ever opening a browser tab.

---

### Speak your language

Insait Edit ships with a built-in UI in **English, Ukrainian, German, Russian, and Turkish**. Need another language? You can import a custom translation in seconds.

---

### Built for Avalonia, WPF, WinForms, and more

Start a new Avalonia, Windows Forms, WPF, console, or class library project from a clean template and hit the ground running. The IDE understands the differences between project types and adapts the build and run experience accordingly.

## Deutsch

**Insait Edit** ist eine moderne Windows-Desktop-IDE für C#- und .NET-Entwickler. Alles, was du brauchst, um von der ersten Idee bis zur fertigen, gepackten Anwendung zu gelangen, ist bereits enthalten — kein Wechsel zwischen Tools, kein Konfigurationschaos.

### Besseren Code schreiben, schneller

Insait Edit kommt mit einem eigens entwickelten Editor, der deinen Code versteht. Während du tippst, schlägt die IDE intelligente Vervollständigungen vor, erklärt was jede Methode tut, findet Fehler noch bevor du das Projekt startest und bietet Korrekturen per Mausklick an. Ob C#, F# oder Avalonia XAML — der Editor hält dir auf jedem Schritt Schritt.

### Alles in einem Fenster

Projekt öffnen, Dateien durchsuchen, in der gesamten Codebasis suchen, NuGet-Pakete verwalten, Git-Verlauf prüfen, die App starten und die Ausgabe lesen — alles ohne die IDE zu verlassen. Ein integriertes Terminal ist immer mit einer Tastenkombination erreichbar.

---

### Vom Code zur gepackten App in Minuten

Insait Edit begleitet den gesamten Lebenszyklus einer Desktopanwendung. Neues Projekt anlegen, während der Entwicklung bauen und ausführen, einen Release veröffentlichen und ihn als signierten MSIX-Installer verpacken — alles in einer Oberfläche, ohne manuelle Befehlszeilen.

Committen, pushen, pullen, Branches und Verlauf durchsuchen — das Git-Panel bietet alles für die tägliche Versionskontrolle. GitHub Copilot CLI ist ebenfalls integriert, damit du KI-Unterstützung bekommst, ohne den Browser öffnen zu müssen.

## Українська

**Insait Edit** — це сучасна Windows-IDE для розробників на C# і .NET. Тут є все необхідне, щоб пройти шлях від ідеї до готового, упакованого застосунку — без перемикання між інструментами та зайвих налаштувань.

---

### Пишіть кращий код, швидше

Insait Edit має власний редактор, який розуміє ваш код. Під час друку IDE пропонує розумні підказки, пояснює що робить кожен метод, знаходить помилки ще до запуску та пропонує виправлення одним кліком. C#, F# чи Avalonia XAML — редактор не відстає від вас.

---

### Все в одному вікні

Відкрити проєкт, переглянути файли, знайти текст по всій кодовій базі, керувати NuGet-пакетами, перевірити Git-історію, запустити застосунок і побачити вивід — все без виходу з IDE. Вбудований термінал завжди під рукою.

---

### Від коду до упакованого застосунку за хвилини

Insait Edit охоплює весь цикл розробки десктопного застосунку. Створіть новий проєкт, збирайте й запускайте під час розробки, опублікуйте реліз і запакуйте його у підписаний MSIX-інсталятор — все в одному інтерфейсі.

---

### GitHub прямо в IDE

Комітити, пушити, пулити, переглядати гілки й історію — Git-панель містить все для щоденної роботи з версіями. GitHub Copilot CLI також інтегровано, щоб ви отримували допомогу ШІ без відкривання браузера.

---

### Говоріть своєю мовою

Insait Edit постачається з інтерфейсом **англійською, українською, німецькою, російською та турецькою**. Потрібна інша мова? Власний переклад можна імпортувати за секунди.

---

### Створено для Avalonia, WPF, WinForms та інших

Розпочніть новий Avalonia-, Windows Forms-, WPF-, консольний або бібліотечний проєкт з готового шаблону і одразу беріться до роботи. IDE розпізнає тип проєкту й адаптує досвід збирання та запуску відповідно.
