**Name:** Insait Edit — C# IDE

**Purpose:** A full-cycle Windows desktop IDE for C# and .NET development, built with Avalonia UI and powered by Microsoft Roslyn. It combines a custom code editor with real semantic analysis — smart completion, inline diagnostics, quick fixes, go to definition, and rename symbol — alongside a built-in Git panel, NuGet package manager, MSIX packaging tools, a terminal, AXAML live preview for Avalonia projects, and F# support. The goal is to have everything needed to write, build, run, publish, and package a .NET desktop application without leaving the IDE. Currently in preview.
